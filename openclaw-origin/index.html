  • 대화 한 번으로 일을 맡기는 고수준 에이전트 도구가 지금 주목받고 있습니다 — OpenClaw는 그 유행을 이끈 오픈소스 가운데 하나
  • 부하직원은 내 컴퓨터에서 늘 켜져 있고, 내가 보내는 메시지를 받고, 내 파일과 도구를 정해 둔 권한 안에서 다룹니다

사연은 바닷가재에서 시작합니다.

이름의 계보

이름사연
Warelay출발점. 당시에는 WhatsApp 메시지를 연결하는 게이트웨이
Clawdbot바닷가재 마스코트 Clawd와 함께. npm 패키지 설명은 "WhatsApp gateway CLI with Pi RPC agent". 2026.1.4~1.24에 39개 버전
Moltbot2026년 1월 Anthropic이 상표 문제로 이름 변경을 요청. 첫 변경 뒤 탈피를 뜻하는 이름
OpenClaw1월 27일 Shelldon·Pinchy 등 수백 개 후보로 커뮤니티 투표 → 1월 30일 확정
🦞 공식 문서는 이 변화를 "New shell, same lobster"라고 표현합니다
npm의 clawdbot 패키지 설명이 이 도구의 초기 정체를 그대로 보여 줍니다 — 소단원 ⑥의 pi 계보와 이어집니다.

이름은 바뀌어도 설치 환경에는 흔적이 남습니다

🐧 Linux · WSL2

예전에 설치한 환경의 systemd 서비스 이름 clawdbot-gateway는 지금도 자동 마이그레이션됩니다

🍎 macOS

옛 실행 설정은 지워지지 않은 채 — 진단 명령이 찾아 알려 줍니다

  • 이 흐름에서 얻는 두 가지 — 상표와 분쟁 때문에 이름이 바뀌어도 코드와 커뮤니티는 이어질 수 있습니다
  • 버전과 문서를 찾을 때에는 현재 이름뿐 아니라 예전 이름도 함께 검색해야 필요한 기록을 놓치지 않습니다
자동 마이그레이션이 어느 OS에 적용되는지가 다르다는 점이 실무 단서입니다.

이 중단원의 순서

순서다룰 것
①~③OpenClaw를 설치하고 세션 기록을 살핍니다
④~⑤텔레그램을 연결하고 보안을 다룹니다
⑥~⑦pi 뼈대를 읽고 멀티에이전트 구성을 읽습니다

이 연결이 실제로 어떻게 만들어지는지 확인합니다
순서 자체가 "입구 → 기록 → 권한 → 확장"이라는 이 강의의 관찰 축과 같습니다.

❓ 이해도 확인

Q1. 이름이 네 번 등장한 순서는?
A1. Warelay → Clawdbot → Moltbot → OpenClaw. 2026년 1월 Anthropic의 상표 문제 요청이 계기.
Q2. 문서를 검색할 때 주의할 점은?
A2. 현재 이름뿐 아니라 예전 이름도 함께 검색해야 기록을 놓치지 않는다.
Q3. 게이트웨이가 하는 일은?
A3. 채널의 메시지를 받아 에이전트 런타임으로 실행을 보내며, 어느 채널의 요청을 어느 세션과 도구로 보낼지 조정한다.
Q3의 "조정"이 이 도구의 정체입니다.
