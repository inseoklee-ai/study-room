공짜의 세계는 줄어드는 중

어제의 무료가 오늘은 없다 — 왜?

Heroku · Railway · Fly.io · Glitch
무료 호스팅을 다룰 때 가장 먼저 알아야 할 사실은, 이 세계가 고정돼 있지 않고 계속 축소되고 있다는 점입니다. 몇 해 사이 초보들이 기대던 서비스들이 잇달아 무료를 접었습니다.

🕰️ 하나씩 사라진 무료 서버들

1Heroku — 한때 초보들의 성지였던 무료 서버가 2022년 11월 완전히 사라짐
2Railway(2023) · Fly.io(2024) — 상시 무료를 없앰
3Glitch — 2025년 7월 앱 호스팅 종료
이 이름들을 외울 필요는 없다. 무료는 언제든 접힐 수 있다는 흐름 자체가 요점이다.
여기 적힌 연도는 각 서비스가 무료 제공을 접은 시점입니다. 지금 이 강의를 듣는 시점에는 또 다른 곳이 명단에 추가돼 있을 수 있습니다. 그래서 특정 서비스에 의존하기보다 흐름을 읽는 것이 안전합니다.

🤔 왜 공짜를 거둬들일까

  • 무료 계정을 암호화폐 채굴 같은 곳에 악용하는 사람이 늘어남
  • 비용 부담이 커지자 회사들이 공짜를 거둬들이기 시작
"지금 무료인 것도
언젠가 바뀔 수 있다"는 전제로 고른다가입 직전에 공식 요금 페이지를 한 번 확인하는 습관이 안전
습관 하나 — 가입 버튼을 누르기 직전, 그 서비스의 공식 요금 페이지를 한 번 확인한다.
무료가 사라지는 배경에는 악용 문제가 있습니다. 소수의 남용이 다수의 무료를 거둬들이게 만든 셈입니다. 그래서 지금 무료라는 정보도 유통기한이 있다고 보고, 가입 직전 공식 요금 페이지를 확인하는 습관을 들이는 것이 안전합니다.

지금 쓸 만한 무료 호스팅

2026 기준 · 정책은 바뀔 수 있음

정적 사이트 · 백엔드 · VM
이제 실제로 남아 있는 선택지를 봅니다. 표를 읽기 전에, 무엇을 올리려는지에 따라 갈 곳이 달라진다는 점을 먼저 짚어 둡니다.

📖 먼저 두 단어만 정리

정적 사이트

화면만 있는 것 — 포트폴리오·소개 페이지 같은 것

백엔드

뒤에서 데이터를 처리하는 부분 — 로그인·저장 같은 일

내가 만든 게 화면만이면 정적, 데이터를 다루면 백엔드가 필요하다.
이 두 단어가 표를 읽는 열쇠입니다. 화면만 있는 것은 가장 단순하고 무료로 올리기 쉽고, 데이터를 처리하는 백엔드가 붙으면 선택지도 제약도 달라집니다.

📊 무료 호스팅 한눈에 비교

서비스뭘 올리기 좋나무료로 주는 것·주의점카드
Cloudflare Pages정적·프론트대역폭 무제한 — 트래픽 걱정 가장 적음불필요
GitHub Pages정적 전용가장 단순, 코드 저장하던 곳에 그대로 게시불필요
Vercel (Hobby)프론트·Next.js손이 가장 덜 감, 단 개인·비상업용만불필요
Netlify정적·프론트Vercel 대안, 상업적 이용 허용불필요
Render백엔드 API15분 안 쓰면 잠듦(다시 깨는 데 ~1분)불필요
Supabase백엔드+DBDB·로그인 한 번에, 7일 미사용 시 일시정지불필요
Oracle Always Free진짜 리눅스 서버(VM)상시 무료 VM, 단 카드 필요·설정 어려움필요
한도·정책은 각 서비스 공식 요금 페이지에서 최신으로 확인한다.
Supabase는 7일 미사용 시 일시정지되며 데이터는 보존되지만 아주 오래 방치하면 삭제될 수 있습니다. 표의 수치와 조건은 2026년 기준이며 정책은 바뀔 수 있으니, 실제 가입 전에는 공식 페이지에서 다시 확인하세요.

이럴 땐 이걸로 시작

내가 만든 것에 맞춰 고르기

포트폴리오 · 프론트 · 백엔드 · 진짜 서버
표를 봐도 막막할 수 있어서, 만든 것의 성격별로 첫 목적지를 정리합니다. 처음에는 이 추천대로 시작하고, 필요가 커지면 그때 옮기면 됩니다.

🎯 상황별 첫 목적지

화포트폴리오·소개 페이지(화면만) → Cloudflare Pages 또는 GitHub Pages
프프레임워크 프론트(Next.js 등) → Vercel (수익 서비스면 나중에 유료로)
DB로그인·저장이 필요한 백엔드+DB → Supabase가 무난한 1순위 (API 서버가 따로 필요하면 Render를 곁들이기)
서진짜 서버를 만져 보며 공부 → Oracle Always Free (설정 난이도 있음)
Supabase를 백엔드 1순위로 추천하는 이유는 DB와 로그인을 한 번에 해결해 주기 때문입니다. 별도의 API 서버 로직이 필요해지면 Render를 함께 쓰는 조합이 흔합니다.

🤖 고르는 것도 AI에게 물어보면 된다

"내가 만든 건 이런 서비스인데, 무료로 올리기 좋은 곳과 그 제약을 표로 정리해 줘"

AI가 후보를 뽑아 주면, 여러분은 그 답을 판단하면 된다.
선택지가 많고 정책이 자주 바뀌는 영역이라, 스스로 전부 조사하기보다 AI에게 후보와 제약을 정리하게 하는 것이 효율적입니다. 다만 최종 판단, 특히 제약이 내 상황에 맞는지는 사람의 몫입니다.

시작 전에 알아 둘 세 함정

무료 티어를 쓰기 전 반드시 확인

잠듦 · 기한/일시정지 · 요금 폭탄
무료 티어에는 유료와 다른 특유의 제약이 있습니다. 미리 알면 당황하지 않고, 데이터를 잃거나 예상치 못한 요금을 맞는 일도 피할 수 있습니다.

⚠️ 무료 티어의 세 가지 함정

1잠듦(spin-down) — 한동안 아무도 안 오면 잠듦. 오랜만의 첫 방문자는 화면 뜨는 데 1분쯤(고장 아님). Render 무료가 대표적
2기한·일시정지 — 무료 DB가 일정 기간 뒤 사라지거나(Render 무료 Postgres는 30일 후 만료), 안 쓰면 잠시 멈춤(Supabase 7일). 중요한 데이터는 백업을 꼭 따로
3요금 폭탄 방지 — 카드가 걸린 서비스(클라우드 VM 등)는 예산 알림·상한을 걸어 둘 것
세 함정 중 초보가 가장 많이 놀라는 것이 잠듦입니다. 오랜만에 접속하면 느려서 고장인 줄 알기 쉽지만, 잠든 서버가 깨어나는 정상 동작입니다. 카드를 등록하는 서비스에서는 예산 상한을 반드시 걸어 요금 사고를 막으세요.

📌 이것만은 꼭 — 핵심 4문장

1무료의 세계는 계속 줄어드는 중 — 가입 직전 공식 요금 페이지를 확인한다.
2화면만이면 Cloudflare Pages·GitHub Pages, 데이터가 붙으면 Supabase부터.
3고르는 것도 AI에게 표로 뽑게 하고, 판단은 내가 한다.
4세 함정 — 잠듦·기한/일시정지·요금 폭탄을 미리 알고 시작한다.
정리 — 무료는 "배우고 시연하기"엔 충분. 많은 사람에게 24시간 안정적으로 제공하는 단계가 오면 그때 유료를 검토한다.
무료 티어의 목적을 분명히 하면 실망할 일이 없습니다. 학습과 시연에는 충분하고, 실제 서비스 규모가 되면 유료 전환을 검토하는 것이 자연스러운 순서입니다.

✅ 정답 & 해설

A1. Heroku — 2022년 11월 무료 제공이 완전히 종료됐다.
A2. 무료 계정을 암호화폐 채굴 같은 곳에 악용하는 사람이 늘어, 비용 부담이 커진 회사들이 공짜를 거둬들였다.
A3. Cloudflare Pages(대역폭 무제한) · GitHub Pages(가장 단순).
A4. Supabase — DB·로그인을 한 번에 해결. API 서버가 따로 필요하면 Render를 곁들인다.
A5. 잠듦(안 쓰면 잠듦) · 기한·일시정지(무료 DB 만료/멈춤, 백업 필수) · 요금 폭탄(카드 걸린 서비스는 예산 상한).
다섯 문항을 자기 말로 설명할 수 있으면 오늘 목표는 달성입니다. 특히 함정 세 가지는 실전에서 데이터와 비용을 지키는 안전장치입니다.
