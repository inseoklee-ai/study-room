맡길 일을
하네스 기능 질문으로 바꾸기

도구 이름부터 고르면 기능 목록을 비교하게 됩니다

이 중단원은 같은 루프를 감싼 일곱 개의 하네스를 열어서, 무엇이 다른지 구조를 확인합니다. 첫 소단원은 도구 비교가 아니라 '내가 맡길 일이 어디서 막히는지'를 찾는 질문법입니다.

먼저 내가 맡길 일이 어디서 막히는지 찾습니다

지난 시간에 나눈 '내가 할 일 · 검토할 일 · 맡길 일'에서 맡길 일 하나를 고릅니다. 반복되는 오류 원인을 모으는 일을 맡겼다면 —

📖 파일을 읽는 일

요청을 받은 뒤 읽기만 하는 행동

✏️ 변경을 실행하는 일

같은 위험이 아닙니다

⚠️ 결과 문장만 보면 이 차이가 사라집니다 — 그래서 실행 환경을 열어 봐야 합니다
도구 이름부터 고르면 기능 목록을 비교하게 됩니다. 순서를 뒤집는 것이 이 소단원의 요지입니다.
1

하네스란 무엇인가

모델이 일하는 동안 무엇을 연결하나

① 하네스 기능 질문
모델의 답변 능력만으로는 이 환경의 차이를 설명할 수 없습니다.

모델을 감싼 실행 환경입니다

1요청
2도구
3기록
4승인
5관측

하네스는 모델이 일을 하는 동안 요청, 도구, 기록, 승인, 관측을 연결하는 실행 환경입니다.

같은 모델도 행동을 적는 형식 · 남겨 둘 문맥 · 허용된 권한이 달라지면
다른 결과를 냅니다
이 문장이 중단원 전체의 전제입니다. "모델이 좋아서" 또는 "모델이 나빠서"로 설명되지 않는 차이의 정체가 하네스입니다.
2

맡길 일이 막히는 곳을 일곱 기능으로 봅니다

도구의 등급표가 아니라 병목의 지도

① 하네스 기능 질문
하네스 기능 지도는 도구의 등급표가 아닙니다. 맡길 일이 멈춘 이유를 찾는 지도입니다.

일곱 기능이 각각 다루는 문제

기능다루는 문제
행동 포맷모델이 읽고, 고치고, 실행하는 행동을 실패하기 어렵게 적게 한다
컨텍스트 관리긴 작업에서 무엇을 남기고 무엇을 줄일지 정한다
경험과 스킬 축적한 번 해결한 일을 다음 작업에 다시 쓴다
반성실행 결과를 살펴 다음 행동을 고친다
단순성필요한 구성만 남겨 운영 부담을 줄인다
권한과 보안읽기·수정·실행의 경계와 승인 방식을 정한다
평가 루프결과가 맞았는지 어떤 근거로 확인할지 정한다
이 일곱 기능이 소단원 ③(행동 포맷) ④(컨텍스트 관리) ⑤(경험·스킬 축적)로 이어집니다.

🎯 이 세 질문은 제품 설명보다 먼저 — 맡길 일의 경계를 드러냅니다
3번이 특히 중요합니다. "기능이 있다"가 아니라 "작동한 기록을 어디서 보나"를 묻는 순간 관찰이 시작됩니다.
3

기능 지도와 비교 카드는 다른 일을 합니다

진단용 제목 vs 관찰 기록 항목

① 하네스 기능 질문
둘을 섞으면 관찰이 흐려집니다.

일곱 기능은 진단, 여섯 칸은 관찰

🗺️ 일곱 기능 (기능 지도)

맡길 일의 병목을 진단하는 섹션 제목

🃏 여섯 칸 (비교 카드)

도구 화면과 문서를 같은 방식으로 관찰하기 위한 기록 항목

카드 칸관찰할 내용
입구요청이 들어가는 화면, 명령, 연결 지점을 확인합니다
상태세션, 대화, 작업 기록이 남는 위치를 확인합니다
대표 행동읽기·검색·수정·실행 가운데 화면에서 확인한 행동을 적습니다
권한 경계읽기 밖의 행동 전에 승인이나 제한이 보이는지 확인합니다
1차 근거실행 기록·설정·공식 문서처럼 나중에 다시 열 수 있는 근거를 연결합니다
한계이번 관찰만으로 확인하지 못한 범위를 구분합니다
기능 지도에서 컨텍스트 관리가 중요하다고 판단한 뒤에도, 카드에서는 상태와 대표 행동이 실제로 어떻게 보이는지 확인합니다.

❓ 이해도 확인

Q1. 하네스를 한 문장으로?
A1. 모델이 일하는 동안 요청·도구·기록·승인·관측을 연결하는 실행 환경. 같은 모델도 형식·문맥·권한이 달라지면 다른 결과를 낸다.
Q2. 도구를 고르기 전에 먼저 물어야 하는 것은?
A2. "내가 맡길 일이 어디서 막히는가." 도구 이름부터 고르면 기능 목록 비교가 된다.
Q3. 세 질문의 마지막이 특히 중요한 이유는?
A3. "그 기능이 작동했다는 기록을 어디서 확인하나"를 물어야 제품 설명이 아니라 관찰이 시작되기 때문.
Q4. 일곱 기능과 여섯 칸의 차이는?
A4. 일곱 기능은 병목 진단용 섹션 제목, 여섯 칸은 도구를 같은 방식으로 관찰하는 기록 항목.
Q4를 섞으면 "기능이 있다"와 "화면에서 봤다"가 뒤엉킵니다.
