제출물 · 목표 · 형식

항목내용
제출물자기 도메인 업무 분해 예시
학습 목표본인의 도메인 전문성을 AI 서비스 관점에서 정리하고, 과정 전체에서 다룰 개인 문제를 초안으로 정의
제출 형식마크다운 문서
[도메인 맥락]
나는 ____ 도메인 ____ 년 차이고, ____ 작업을 자동화/정리하고 싶습니다.

[네 동작 분석]
1. 분해: ____      2. 패턴: ____
3. 추상화: ____    4. 알고리즘: ____

[출력 요구]      ____ 형식으로, 한국어로.
[검증 기준]      ____ 한 사람이 ____ 라고 평가할 것.
🔍 한 칸이라도 비어 있다면 그 칸은 "아직 또렷하게 생각하지 못한 부분"입니다. 가장 자주 비는 칸은 [검증 기준] — "누가·어떤 기준으로" 합격을 판단하는지 적어야 AI가 그 기준에 맞춥니다. 검증 기준은 도메인 전문가만 정할 수 있는 칸입니다.

실제 제출 예시

AI Agent 도입 컨설팅 · 블로그 발행 프로세스

⑤ 제출
실제로 제출된 예시입니다. 도메인이 '컨설팅'이라 코딩과 거리가 멀어 보이지만 네 동작이 또렷하게 들어갔습니다.

예시 — 도메인 맥락과 네 동작

[도메인 맥락]
나는 중소기업 대상 AI Agent 도입 컨설팅을 하는 1인/소규모 사업자이고,
서비스 홍보를 위해 매일 AI 관련 블로그 글 1개를 발행하고 싶습니다.
분해소재수집 → 소재선별 → 카테고리분류(트렌드/사례/성과) → 핵심메시지추출 → 초안작성 → CTA삽입 → 검토 → 발행 8단계
패턴트렌드형·도입사례형·성과형 3가지 유형별로 반복되는 문장 구조(도입-전개-시사점-CTA) 발견
추상화3가지 유형을 "빈칸만 채우면 되는" 마스터 템플릿 3종으로 일반화. 과장 수치·과도한 기술 디테일은 제거
알고리즘매일 소재 수집 → 유형 배정(요일별 캘린더) → 템플릿에 소재 대입 → 체크리스트 검토 → 발행 → 성과 기록(주/월 피드백 루프)
제출 예시: 이인석 — https://github.com/iamgod2983/hello-aiffel (Computational Thinking-이인석.md). 분해가 8단계까지 내려간 것과, 추상화에서 '무엇을 버릴지'까지 적은 것이 좋은 지점입니다.

예시 — 출력 요구와 검증 기준

[출력 요구]
매일 발행 가능한 블로그 콘텐츠 생성 프로세스 문서로, 한국어로.

[검증 기준]
실제로 매일 1시간 이내에 초안을 완성할 수 있고,
중소기업 대표가 읽고 "우리 회사 얘기 같다"고 느낄 것.
1측정 가능한 기준 — "매일 1시간 이내에 초안 완성"
2누가 판단하는지 명시 — "중소기업 대표가 읽고"
3도메인 전문가만 아는 합격선 — "우리 회사 얘기 같다고 느낄 것"
💎 이게 좋은 [검증 기준]입니다 — AI가 스스로 정할 수 없는 기준이고, 그래서 사람이 정해 줘야 하는 칸
"잘 작동하면 좋겠어"와 비교해 보여 주면 차이가 확연합니다. 시간 기준·판단 주체·정성 기준 세 가지가 다 들어 있습니다.

📦 제출
평가 기준을 미리 보여 주고 과제를 하게 하면 결과가 훨씬 좋아집니다.

루브릭과 제출 방식

학습목표평가기준
문제를 분해했는가도메인 문제를 더 작은 하위 문제로 나누어 제시합니다
절차로 표현했는가해결 과정을 순서가 있는 단계로 작성합니다
패턴·추상화를 적용했는가반복 구조를 패턴으로 정리하고 핵심만 남기는 추상화를 수행합니다
!ZIP · PDF · 이미지만 첨부 가능 (최대 5MB) 또는 URL 업로드
!파일 또는 URL 중 한 가지 방식으로만 업로드 가능
!제출 후 수정은 불가 — 링크가 열리는지, 저장소가 public인지 미리 확인
루브릭 세 항목이 네 동작 중 분해·알고리즘·(패턴+추상화)에 그대로 대응합니다. 네 동작을 채웠다면 자연히 충족됩니다.

🎯 핵심 정리 — 손에 쥐고 갈 것

소단원손에 쥐고 갈 것
①핵심 한 문장 — 컴퓨팅 사고법 = 큰 문제를 AI가 풀 수 있는 작은 조각으로 나누는 사고법
②하나의 사고법, 네 동작 — 분해·패턴 인식·추상화·알고리즘. 한 사이클로 오감
③나는 이미 이 사고법을 쓰고 있다 + 컴퓨팅 사고법이 못 푸는 영역(창의·맥락·가치 판단)은 사람의 자리
④내 도메인 문제 한 가지를 네 동작으로 쪼갠 한 페이지 + AI 전달 형식 초안
네 줄 중 ③이 이 강의의 태도이고, ④가 산출물입니다.

❓ 마지막 확인

Q1. 제출 루브릭 세 항목은 네 동작 중 무엇에 대응하나?
A1. 분해 / 알고리즘(절차) / 패턴+추상화. 네 동작을 성실히 채우면 자연히 충족된다.
Q2. 좋은 [검증 기준]의 요소는?
A2. 측정 가능한 기준 + 누가 판단하는지 + 도메인 전문가만 아는 합격선. 예: "매일 1시간 이내에 초안 완성 / 중소기업 대표가 '우리 회사 얘기 같다'고 느낄 것".
Q3. OT 3일을 한 줄로 잇는다면?
A3. 출발점(Day 1)에 서서, 막혀도 버틸 루틴(Day 2)을 들고, AI에게 일을 또렷하게 시키는 사고법(Day 3)으로 내일부터 첫 결과물을 만들러 간다.
Q2의 예시는 실제 제출물에서 나온 것입니다 — 학습자에게 자기 기준을 다시 써 보게 하면 좋습니다.
