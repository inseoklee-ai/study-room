pi
— 내 에이전트 툴의 뼈대

에이전트 툴은 마법 상자가 아니라 조립할 수 있는 층위입니다

pi는 터미널에서 쓰는 작은 코딩 에이전트 CLI입니다.

여기서 pi를 소개하는 까닭

pi를 기반으로
내 필요에 맞춘 에이전트 툴을 만들 수 있기 때문입니다
  • pi는 모델과 도구를 연결해 코딩 작업을 돕는 기능을 담고 — 스크립트로 확장할 자리를 열어 둡니다. 그래서 화면 뒤에서 어떤 부분을 바꾸고 어떤 부분을 덧붙일지 읽을 수 있습니다
  • 완성된 서비스를 그대로 쓰는 데서 멈추지 않고, 필요한 입구와 기능을 코어 위에 얹는 선택도 가능합니다
📌 이 선택은 이미 일어난 일입니다 — 한 때 OpenClaw는 pi를 에이전트 엔진으로 채택했습니다. WhatsApp 메시지 입구를 pi 엔진에 연결하는 작은 도구에서 출발해 지금에 이르렀습니다
코어를 골라 그 위에 도구를 키우는 일이 실제로 작동했다는 뜻입니다.

작은 코어는 적은 기능이라는 뜻만은 아닙니다

나누어 볼 것도구
나누어 볼 것모델
나누어 볼 것기록
나누어 볼 것확장
  • 이 넷을 어디에 둘지 나누어 볼 수 있다는 뜻입니다
  • 먼저 코어가 맡은 일을 읽고, 바깥에 더할 일을 고르면 됩니다
"기능이 몇 개인가"보다 "어느 층에 있는가"를 묻는 관점입니다.
1

pi 안을 들여다봅니다

화면 · 모델 · 세션 · 도구

⑥ pi 뼈대
pi의 기본 화면은 터미널 TUI입니다.

모델에 연결하는 세 갈래

길내용
OAuthClaude Pro 또는 Max 구독으로 — 로그인 권한을 맡기는 방식
API 키키를 등록해 제공자에 연결
로컬 Ollama모델을 등록해 컴퓨터 안의 모델을 고름
📌 OpenClaw에서 살핀 두 인증 경로와 비교하면 — pi에는 로컬 모델 경로가 하나 더 있습니다. 같은 에이전트 화면이라도 모델을 만나는 방식은 도구마다 다르게 설계됩니다
기본 화면은 터미널 TUI(터미널 안에서 움직이는 화면)입니다. 여기에서 모델과 대화하고 코딩 도구를 호출하는 흐름이 이어집니다.

세션은 JSONL로 남습니다

  • 대화는 화면에서 사라져도 세션 기록으로 남을 수 있습니다. 기본 위치는 ~/.pi/agent/sessions/
  • 작업 경로마다 JSONL 파일이 쌓입니다 — JSONL은 한 줄마다 JSON 객체 하나를 넣는 기록 형식
  • 첫 줄에는 세션 ID · 시각 · 작업 폴더 경로가, 이후 줄에는 대화와 도구 호출 결과가 이어집니다
🎯 그래서 화면의 답변과 실제 호출을 따로 볼 수 있습니다 — 소단원 ③의 toolCall/toolResult 구분과 같은 이야기
  • 도구도 처음부터 모두 열어 둘 필요는 없습니다 — --tools 옵션으로 허용할 도구 목록을 정합니다. 읽기만 맡길 때와 파일을 바꾸게 할 때의 경계가 여기에서 갈립니다
도구 목록이 곧 권한이라는 원칙이 pi에서도 --tools로 나타납니다.

⑥ pi 뼈대

없는 것과 어디에 둘 것인가

pi에 없는 것어디에서 맡을 수 있는가
내장 MCP 클라이언트확장으로 더할 수 있음
내장 서브에이전트여러 pi를 함께 다루는 방식을 확장이나 별도 구성으로 설계
내장 스케줄러운영체제의 예약 기능이나 별도 확장
🎯 이 빈자리는 부족한 목록으로만 끝나지 않습니다 — 무엇을 코어에 두고 무엇을 확장으로 둘지 고르는 경계가 됩니다
  • OpenClaw에서는 채널 연결·권한 모드·자동화 예약을 하나의 도구에서 보았습니다. pi는 그 기능들을 기본으로 모두 품지 않는 대신 — 필요한 부분을 바깥에서 조립할 여지를 남깁니다
  • 기능이 있는지뿐 아니라 어느 층에 놓였는지도 살펴야 합니다
중단원 ②(하네스)의 미니멀 절과 같은 논리입니다.

❓ 이해도 확인

Q1. pi가 OpenClaw와 다른 모델 연결 경로는?
A1. 로컬 Ollama 모델 경로. OpenClaw의 두 경로(API 키·claude-cli)에 하나가 더 있다.
Q2. pi에 없는 세 가지와 그 뜻은?
A2. MCP 클라이언트 · 서브에이전트 · 스케줄러. 부족함이 아니라 코어와 확장의 경계를 정한 설계.
Q3. pi의 계보가 보여 주는 것은?
A3. 코어를 골라 그 위에 입구와 기능을 얹으면 다른 도구가 된다는 것. Warelay·Clawdbot이 그렇게 만들어졌고, 이후 자체 코어로 pi 의존을 걷어냈다.
Q2가 이 소단원의 관점입니다.
