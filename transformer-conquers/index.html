1

언어 안, 세 번의 도약

사전학습으로 삼키고, 스케일로 창발하고

BERT·GPT · 스케일링 · 인컨텍스트 러닝
트랜스포머는 원래 문장을 읽는 인코더와 쓰는 디코더가 짝을 이룬 구조였습니다. 이후 연구는 한쪽만 떼어 극단으로 밀어붙이는 두 갈래로 갈립니다.

🍴 사전학습의 두 갈래

📖 BERT (2018) · 인코더만

문장의 단어 일부를 가리고 앞뒤 문맥을 모두 보고 빈칸 맞히기 = 양방향 마스크 LM. 의미를 깊이 이해하는 분류·검색에 강함.

✍️ GPT 계열 · 디코더만

오직 다음 토큰 하나 예측. 앞 문맥 → 다음 단어 확률 → 뽑아 이어 붙이고 반복. 글을 생성하는 데 자연스러움.

두 갈래 모두 웹 규모 텍스트로 언어 통계를 크게 익혀 두고(사전학습), 과제마다 적은 데이터로 손보는(파인튜닝) 흐름을 공유했다 — 곧 이 당연함이 무너진다.
BERT: arXiv:1810.04805. 인코더=이해, 디코더=생성이라는 두 성격이 여기서 갈립니다.

📈 키웠더니 — 스케일링 법칙 (2020)

  • GPT 계열은 구조를 바꾸는 대신 그냥 더 키웠다 — GPT-2(2019)는 15억 개, 파인튜닝 없이도 그럴듯한 글
  • "얼마나 키우면 얼마나 좋아지나?" → 모델·데이터·계산량을 키우며 재 보니
  • 손실(틀린 정도)이 뚝 떨어지는 게 아니라, 자원을 몇 배 할 때마다 정해진 비율로 매끈하게 감소 = 멱법칙
GPT-2 · 201915억 · 손실 높음
규모(로그)↑ →
GPT-3 · 20201,750억 · 손실 낮음
성능 향상이 요행이 아니라, 자원을 부으면 예측 가능하게 따라오는 공학의 문제임을 보인 것. (Scaling Laws, arXiv:2001.08361)
손실은 틀린 정도를 숫자 하나로 요약한 값, 작을수록 잘 맞힌 것입니다.

🔬 깊이 보기 — 멱법칙을 식으로

L ∝ N−α
L=손실 · N=파라미터 수 · ∝=비례 · α=감소 기울기(작은 양수)
  • 지수 앞의 마이너스 = N이 커질수록 손실이 내려간다는 뜻
  • 데이터 양·계산량에도 같은 모양의 식이 성립 — 일부 추세는 일곱 자릿수 범위에서도 안 흐트러짐
  • 관찰: 큰 모델일수록 같은 데이터에서 더 많이 뽑아낸다 → 예산이 정해지면 작은 모델 오래보다 큰 모델을 비교적 적은 데이터로
요컨대 규모↑ → 손실↓가 자로 잰 듯 예측된다는 것이 스케일링 법칙의 핵심입니다.
이 "큰 모델이 유리하다"는 관찰이 이후 초거대 모델 경쟁의 이론적 근거가 됩니다.

✨ GPT-3와 솟아난 능력 — 인컨텍스트 러닝

  • 2020년 GPT-3는 1,750억 개. 놀라운 건 낮은 손실이 아니라 아무도 안 가르친 능력이 솟은 것
  • 인컨텍스트 러닝 — 가중치를 하나도 안 바꾸고, 입력 창에 예시 몇 개만 적어 새 과제 수행
  • "영어→프랑스어" 예시 두세 쌍을 보여 준 뒤 새 문장을 던지면, 그 자리에서 패턴을 흉내 내 답 (= 퓨샷)
과제는 이제 훈련의 대상이 아니라
프롬프트에 적어 넣는 지시가 되었다다시 학습시키는 대신 말로 시키는 시대 — 지금 우리가 프롬프트를 쓰는 방식의 뿌리
Language Models are Few-Shot Learners, arXiv:2005.14165. 방금 전까지 당연했던 "과제마다 파인튜닝" 워크플로가 통째로 뒤집혔습니다.
2

똑똑하지만 말귀를 못 알아듣던 모델

다음 토큰 잇기 ≠ 사람이 원하는 것

정렬 · SFT · RLHF · DPO
사전학습을 마친 모델은 방대한 지식을 품었지만, 훈련 목표가 오직 "다음에 올 법한 토큰 잇기"뿐이었습니다. 이 간극을 메우는 작업이 정렬입니다.

🙉 "다음에 올 법한" ≠ "사람이 원하는"

사전학습만 마친 모델에게 프랑스의 수도를 알려 줘 → 답을 아는데도 "이탈리아의 수도도 알려 줘"라고 비슷한 질문을 이어 쓴다. 인터넷엔 질문 뒤 질문이 이어지는 텍스트가 널려, 그것이 통계적으로 그럴듯한 다음 토큰이었으니까.

  • 모델은 지시를 따르도록·정직하게·해로운 요청을 거절하도록 만들어진 적이 없다
  • 정렬 = 트랜스포머가 매 순간 내놓는 다음 토큰 확률 분포를 원하는 쪽으로 미는 작업
곧 강화학습이 등장 — 정답을 알려 주는 대신 잘한 행동에 보상. 보상을 좇는 주체(정책)가 바로 트랜스포머 언어 모델 자신. 구조를 아는 지금이라야 "무엇을 어디로 미는지"가 말이 된다.
정렬을 트랜스포머 직후에 다루는 이유가 이것입니다. 정렬은 허공의 마법이 아니라 토큰 분포를 미는 구체적 작업입니다.

1️⃣ 첫 손질 — 지시학습(SFT)

  • 사람이 좋은 질문 + 모범 답안 쌍을 여럿 써 두고, 그 답안이 나올 확률이 커지도록 미세조정
  • 중요 — 이 단계는 새 지식을 심지 않는다. "파리가 프랑스 수도"는 이미 사전학습에 들어 있음
  • SFT가 바꾸는 건 지식을 꺼내는 행동의 양식 — 질문에 질문 말고 지시가 오면 수행하라는 대화의 매너
SFT만으로도 눈에 띄게 쓸 만해진다. 다만 모범 답안은 양이 한정적이고, "무엇이 더 좋은 답인가"는 답 하나를 베껴선 전해지지 않는다.
supervised fine-tuning. 사실을 새로 심는 게 아니라 태도를 조각한다 — 정렬 전체를 관통하는 핵심입니다.

2️⃣ 사람 선호로 다듬다 — RLHF

  • 같은 질문에 모델이 낸 여러 답을 사람에게 보여 주고 어느 쪽이 나은지 고르게 한다
  • 절대 점수는 어려워도 둘 중 나은 쪽 고르기는 쉽다는 사람 판단의 결을 이용
  • 모은 비교로 보상 모델(심판)을 학습 → 그 점수가 높아지는 쪽으로 토큰 분포를 이동
  • KL 제약 — 손질 전 모델에서 멀어진 만큼 벌점, 심판 허점 파고드는 폭주 방지
GPT-3에 적용한 InstructGPT — 130배 작은 13억 모델의 답을
1,750억 원본보다 사람들이 더 선호크기 100배를 정렬 하나가 뒤집었다 — ChatGPT의 바탕
Deep RL from human preferences, arXiv:1706.03741 / InstructGPT, arXiv:2203.02155. 쓸 만함은 크기만의 문제가 아니었습니다.

🔬 깊이 보기 — SFT·RLHF의 목적함수

πθ = 우리가 훈련하는 모델(정책) · σ = 실수를 0~1로 누름
SFT :　L = − E [ log πθ(y | x) ]　← 모범답안 확률 최대(최대우도)
보상모델 :　L = − E [ log σ( r(x,yw) − r(x,yl) ) ]
정책 :　max E[ r(x,y) ] − β·KL( πθ ‖ πref )
  • 보상모델 — 이긴 답 yw 점수가 진 답 yl보다 클수록 손실↓ (사람이 고른 쪽에 높은 점수)
  • 정책 — 앞항 보상 높이기 + 뒷항 기준 πref에서 멀어진 만큼 벌점(KL 고삐). β가 고삐 세기
  • 보통 PPO로 조금씩만 움직여 학습이 안 무너지게
KL은 두 확률분포가 얼마나 벌어졌는지 재는 값. 이 벌점이 없으면 보상 허점만 파고들어 언어 능력이 망가집니다.

3️⃣ 보상 모델을 지우고 곧장 — DPO (2023)

  • RLHF는 강력하지만 무겁다 — 보상 모델 따로 학습 + 불안정한 RL + 훈련 내내 답 생성
  • DPO의 질문: 목표가 선호에 맞는 정책이라면, 보상 모델·RL을 건너뛰고 선호 쌍에서 곧장?
  • KL 고삐 걸린 보상 최대화를 종이 위에서 풀어 뒤집으면 보상이 정책 자신의 확률 비로 바뀐다
  • 그러면 보상 모델이 통째로 사라지고 — 이긴 답 확률↑ 진 답 확률↓의 분류 손실 하나만 남는다
RLHF와 같은 목표를 지도학습 한 번으로 겨냥 → 단순·안정. 이후 여러 오픈 모델이 채택. (DPO, arXiv:2305.18290)
"Your Language Model is Secretly a Reward Model" — 언어 모델 자체가 이미 보상 모델 역할을 품고 있다는 통찰입니다.

🔬 깊이 보기 — 보상 모델이 사라지는 과정

  • KL 제약 보상 최대화는 닫힌 형태의 해(종이 위 수식 하나로 딱 떨어짐)로 적힌다
  • 그 해를 뒤집으면 보상 = 정렬 정책과 기준 정책의 확률 비, 즉 r = β·log( πθ / πref )
  • 이를 선호 비교 식에 대입하면 보상 모델 r이 통째로 소거되고 다음만 남는다
LDPO = − E [ log σ( β·log πθ(yw)/πref(yw) − β·log πθ(yl)/πref(yl) ) ]
하는 일은 직관적 — 고른 답 yw 확률은 기준 대비 올리고, 진 답 yl 확률은 내린다. β·πref가 KL 고삐를 그대로 이어받아 원래 능력에서 못 벗어나게 잡아 준다.
RLHF의 3부품(보상모델+RL+생성)을 수식 조작으로 지도학습 1회로 접은 것이 DPO의 우아함입니다.

🧩 정렬의 정체 — 태도를 조각한다

단계학습 신호파라미터의 무엇이 바뀌나대가
사전학습웹 텍스트의 다음 토큰세계 지식 + 언어의 통계막대한 계산량
지시학습(SFT)사람이 쓴 모범 답안지식을 꺼내는 행동 양식모범 답안 작성 비용
강화학습(RLHF)답들 사이 사람 선호선호하는 쪽으로 분포 이동보상 모델·불안정 RL
직접 최적화(DPO)답들 사이 사람 선호RLHF와 같으나 절차만 단순선호 데이터 품질 의존
사전학습지식을 쌓다
→
지시학습 SFT행동을 가르치다
→
선호 정렬 RLHF·DPO가치를 입히다
핵심 한 문장 — 아는 것은 대체로 사전학습에서 정해지고, 정렬은 그 아는 것을 어떻게 말하고 행동할지를 바꾼다.
네 단계는 경쟁자가 아니라 파라미터의 서로 다른 층위를 차례로 건드리는 흐름입니다. 사실을 심는 게 아니라 태도를 조각합니다.

언어의 울타리를 넘다

토큰으로 자를 수 있으면 무엇이든 삼킨다

ViT · Whisper · DiT · AlphaFold · RT-2
정렬이 마지막 퍼즐을 맞추자 모델은 쓸 만해졌고, 진짜 사건은 그다음 — 트랜스포머가 언어를 떠나기 시작한 것입니다.

🔑 넘어간 이유는 허무할 만큼 단순

  • 어텐션은 애초에 언어에 대한 계산이 아니었다
  • 하는 일 = 여러 조각이 서로를 둘러보며 누구를 얼마나 참고할지 정하는 것뿐
  • 그 조각이 꼭 단어여야 한다는 조건은 어디에도 없었다
무엇이든 조각으로 잘라 한 줄로 세울 수만 있다면
픽셀이든 소리든 로봇의 관절 각도든 똑같이 삼킨다
이 한 줄이 열쇠였고, 열쇠를 쥔 사람들이 분야마다 문을 열고 들어갔다.
"조각으로 자르고, 서로를 참고하게 한다" — 이 추상이 분야를 가리지 않는 이유입니다.

CNN — 공짜 전제

필터 구조 자체에 "가까운 픽셀은 관련 있다"·"같은 무늬는 어디 있든 같다"가 이미 박혀 있음. 학습이 아니라 설계로 얻은 지식.

ViT — 전제 없음

모든 패치가 모든 패치를 평등하게 둘러봄. 이웃이 특별하다는 사실마저 데이터에서 배워야 함.

그래서 데이터가 적을 땐 CNN에 밀렸고, 3억 장 규모로 사전학습한 뒤에야 앞섰다. 공짜 전제를 버린 대신 전제에 갇히지 않는 자유를 얻은 거래 — 데이터 흔한 시대엔 남는 장사.
이 "귀납 편향(inductive bias)을 버리고 데이터로 대체한다"는 거래가 트랜스포머 정복의 공통 대가입니다. 확산(DiT)은 U-Net을 들어내고 잠재 패치를 토큰으로 세웠고, 요즘 Stable Diffusion 3·CogVideoX가 이 뼈대 위에 섭니다.

🧭 여기까지의 여정

물음핵심 정리
사전학습은 무엇을 남기나다음 토큰 예측만으로 세계 지식·언어 통계를 파라미터에 쌓는다
스케일은 무엇을 바꿨나멱법칙으로 성능↑, 파인튜닝 대신 프롬프트로 시키는 인컨텍스트 러닝 창발
정렬은 무엇을 바꾸나지식이 아니라 행동·선호. SFT가 매너를, RLHF·DPO가 가치를 입힌다
왜 언어 밖으로 번졌나어텐션은 조각들이 서로를 참고하는 계산 — 토큰으로 자를 수 있으면 무엇이든
활용가에게 무엇이 남나구조 하나를 알면 시각·음성·생성 모델까지 같은 눈으로 읽고 같은 잣대로 비용을 딴다
트랜스포머 한 구조가 인터넷을 삼키고, 규모로 창발하고, 사람의 선호로 다듬어진 뒤, 언어의 울타리마저 넘은 여정이었습니다.

📌 이것만은 꼭 — 핵심 5문장

1사전학습은 다음 토큰 예측만으로 지식·언어 통계를 쌓는다. BERT=이해, GPT=생성.
2스케일링 법칙(멱법칙)으로 성능이 예측 가능하게 오르고, GPT-3에서 인컨텍스트 러닝이 창발 → 프롬프트 시대.
3정렬은 지식이 아니라 태도 — SFT(매너) → RLHF/DPO(선호). "아는 건 사전학습, 태도는 정렬."
4어텐션은 조각들이 서로를 참고하는 계산일 뿐 → ViT·Whisper·DiT·AlphaFold·RT-2로 언어 밖 정복.
5활용가는 두 질문으로 — "무엇을 토큰으로 잘랐나 · 무엇이 무엇을 참고하나". 비용은 조각 수가 가른다.
3번과 4번이 오늘의 심장입니다. 태도를 조각한다는 것, 그리고 조각으로 자르면 무엇이든 삼킨다는 것.

🎯 이해도 확인 질문

Q1. BERT와 GPT는 트랜스포머의 어느 쪽을 떼어 냈고, 각각 무엇에 강한가?
Q2. 스케일링 법칙과, GPT-3에서 창발한 인컨텍스트 러닝이 바꾼 워크플로는?
Q3. 사전학습만 한 모델이 지시를 안 따르는 이유와, 정렬이 바꾸는 것은?
Q4. RLHF와 DPO의 차이는? DPO는 무엇을 지웠나?
Q5. 어텐션이 언어 밖으로 번질 수 있었던 이유를 한 문장으로.
Q3·Q5가 오늘의 핵심입니다. 태도 조각, 그리고 조각화의 보편성.

✅ 정답 & 해설

A1. BERT=인코더만(양방향 마스크 LM)→이해·분류·검색. GPT=디코더만(다음 토큰 예측)→생성.
A2. 규모↑→손실↓가 멱법칙으로 예측. 인컨텍스트 러닝으로 과제가 훈련 대상 → 프롬프트 지시로 바뀜(다시 학습 대신 말로 시키기).
A3. 목표가 "다음에 올 법한 토큰"뿐이라 지시·정직·거절을 배운 적 없음. 정렬은 지식이 아니라 행동·선호(태도)를 바꾼다.
A4. RLHF=보상 모델+불안정한 RL로 선호 반영. DPO=보상 모델·RL을 지우고 선호 쌍에서 곧장 최적화(지도학습 1회). 단순·안정.
A5. 어텐션은 조각들이 서로를 참고하는 계산일 뿐, 조각이 단어일 필요가 없어 토큰으로 자를 수 있으면 무엇이든 삼킨다.
A3·A5를 자기 말로 설명할 수 있으면 트랜스포머 강의 전체를 손에 쥔 것입니다.
