🏦 은행 창구에서 시작됩니다

1990년대 후반, 수표에 손으로 적은 숫자를 기계가 읽게 하려는 시도. 당시 컴퓨터 비전의 상식은 —

  • 사람이 먼저 "숫자의 모서리는 이렇게, 곡선은 저렇게" 하고 특징을 손으로 설계해 뽑아낸 뒤, 단순한 분류기에 넘김
  • 문제: 손글씨는 사람마다 제멋대로 → 미리 정한 특징 규칙이 조금만 벗어난 글씨 앞에서 쉽게 무너짐
종이에 적힌 숫자를 기계가 대신 읽게 하려던 이 실무의 요구가 최초의 CNN을 불러냈습니다.
(수표 판독기 사진 — Guillaume Capron, CC BY-SA 2.0.) 실무의 곤란이 새 발상의 출발점이었습니다.

💡 특징을 데이터가 스스로 배우게 — CNN

  • 특징을 사람이 정하지 말고 픽셀에서 곧바로 신경망이 스스로 배우게 하자
  • 작은 필터를 이미지 위에서 미끄러뜨리며 국소 무늬(가장자리·모서리·곡선)를 훑고, 같은 필터를 이미지 전체에 재사용해 파라미터를 크게 줄임
  • = CNN(합성곱 신경망) — 필터를 겹쳐 곱하고 더하는 계산. 같은 필터를 돌려 쓰니 화면 어느 구석이든 같은 무늬를 알아봄
🔑 이 초기 신경망(1998)은 손글씨 숫자를 놀랍도록 안정적으로 읽어냈고 실제 수표 판독기로 상용화까지 됐습니다.
합성곱(convolution)이라는 이름은 필터를 이미지에 겹쳐 곱하고 더하는 계산에서 왔습니다.

😴 시대를 앞선 발상, 14년 뒤 부활

왜 잠들었나

신경망 학습엔 방대한 데이터 + 계산력이 필요한데 당시엔 둘 다 부족 → 발상은 서랍 속으로, 세상은 한동안 신경망을 잊음

무엇이 바뀌었나

① 인터넷에 쌓인 라벨 붙은 이미지 수백만 장(+매년 겨루는 대회 ILSVRC)
② 게임용 GPU가 신경망의 대량 병렬 계산에 완벽히 들어맞음

🔑 훌륭한 발상도 데이터와 계산력이라는 두 조각이 갖춰지기 전까지는 잠들어 있었습니다.
게임 화면을 그리려고 태어난 GPU가 딥러닝의 엔진이 된 순간입니다.

🔫 2012 — 부활의 방아쇠

한 팀이 데이터셋 + GPU를 CNN에 결합해 대회에 나갔고, 결과는 충격이었습니다.

  • 해마다 조금씩 깎이던 숫자를 단숨에 무너뜨린 딥러닝 부활의 방아쇠
이 모델(AlexNet)이 딥러닝 부활의 방아쇠라 불립니다.

🧪 승리를 만든 재료

ReLU음수면 0으로 누르고 양수면 통과시키는 단순한 장치. 이 작은 꺾임이 없으면 층을 아무리 쌓아도 전체가 하나의 직선으로 뭉개짐
dropout학습마다 뉴런 일부를 무작위로 꺼 0만 내보내게 함 → 특정 뉴런에 답을 새겨 넣지 못해 외우는 대신 규칙을 익힘
GPU×2파라미터 6천만 개 신경망을 GPU 두 장으로 학습
⚠️ 과적합 = 훈련 데이터를 이해하는 대신 통째로 외워 버려, 연습 문제는 다 맞는데 처음 보는 문제에서 무너지는 현상. dropout이 이걸 막습니다.
특징을 사람이 짜 넣던 시대가 끝나고, 데이터가 특징을 스스로 길러내는 시대가 열렸음을 증명했습니다.

더 깊게, 그리고 깊이의 벽

"깊을수록 좋다"가 어느 선에서 뒤집힌다

vanishing gradient
방아쇠가 당겨지자 모두 같은 방향으로 달렸습니다 — 더 깊게 쌓자. 층이 깊어질수록 낮은 층은 단순한 무늬를, 높은 층은 눈·바퀴·얼굴 같은 복잡한 개념을 조합합니다.

📈 2014 — 더 깊게

VGG

3×3짜리 작은 필터만 규칙적으로 층층이, 최대 19층 → 준우승(약 7.3%)

GoogLeNet

서로 다른 크기 필터를 한 묶음에 병렬로 넣는 모듈을 22층 → 우승 6.7%

불과 2년 전 15.3%였던 오류율이 절반 이하로. 여기까지는 "깊을수록 좋다"가 잘 맞았습니다.
그런데 층을 더, 더 얹으려 하자 이상한 일이 벌어집니다.
낮은 층=가장자리 같은 단순 무늬, 높은 층=복잡한 개념 조합. 그러니 층을 더 얹으면 더 똑똑해질 것 같았습니다.

🧱 깊이의 벽 — 더 깊은데 더 나쁘다

  • 어느 선 이상 쌓으면 더 깊은 신경망이 얕은 것보다 오히려 성적이 나빠짐
  • 과적합이 아님 — 과적합이라면 훈련 데이터는 잘 맞혀야 하는데, 이 깊은 신경망은 훈련 데이터에서마저 더 못 맞힘 → 학습 자체가 안 됨

범인: vanishing gradient

출력의 오차를 뒤에서 앞으로 되짚으며 각 층을 고치는데, 신호는 층을 하나 통과할 때마다 그 층의 기울기가 곱해짐. 이 값이 대개 1보다 작아, 수십·수백 번 곱하면 순식간에 0에 수렴 → 앞쪽 층엔 "무엇을 고쳐라"는 지시가 사실상 도착하지 않음

🔑 기울기 = "이 숫자를 조금 바꾸면 결과가 얼마나 달라지는가". 깊이는 축복이 아니라 저주가 됐고, 이것이 이미지 진영이 만난 깊이의 벽입니다.
학습 신호가 긴 사슬을 거치며 점점 흐려지는 것 — 이 '모양'을 기억해 두세요.
2

벽을 뚫은 지름길 — ResNet

신호가 곧장 흐르는 뒷길을 하나 터 준다

skip connection · 잔차
신호가 층을 하나하나 통과하며 약해진다면, 몇 개 층을 건너뛰고 곧장 앞으로 흐르는 지름길을 하나 놓아 주면 되지 않을까 — 놀랄 만큼 간단한 발상이었습니다.

🛤️ 일반 블록 vs 잔차 블록

일반 블록

입력 x
↓
층들이 H(x)를
통째로 학습
↓
출력 H(x)

잔차 블록 (ResNet)

입력 x
↓   ↘ 지름길 x
층들이 잔차 F(x)만
↓   +
출력 F(x) + x
F(x) = H(x) − x · 출력 = F(x) + x = H(x)
층에게 정답 H(x)를 통째로 만들라 하지 않고, 정답에서 입력을 뺀 나머지(잔차)만 만들라 하고 입력을 지름길로 더해 복원합니다.

🔑 이 덧셈 하나가 왜 벽을 뚫나

①학습 신호의 고속도로 — 층을 통과하면 기울기가 곱해져 약해지지만, 지름길은 입력을 그대로 더한 통로라 되짚을 때 기울기가 1. 신호가 곱셈에 안 깎이고 앞쪽까지 온전히 흐름
②아무것도 안 하기가 쉬워짐 — 필요 없는 층은 F(x)=0만 만들면 출력이 0 + x = x(항등 변환). 필요 없는 층은 조용히 비켜서고 필요한 층만 일함 → 마구 쌓아도 나빠지지 않음
🔑 큰 목표를 통째로 조각하는 대신 기준선(x)에서 얼마나 벗어나는지 그 차이만 다듬게 하니 학습이 훨씬 수월. 정답이 입력과 크게 다르지 않은 층일수록 만들 잔차가 작아 부담↓.
여러 비선형 층을 통과시키며 입력을 조금도 안 바꿔 그대로 내보내는 건 의외로 어려운데, 잔차 구조에선 F(x)=0으로 저절로 됩니다.

🏆 결과 — 깊이의 벽이 무너지다

지름길 하나로 152층이 안정 학습
2015 top-5 오류율 3.57%
같은 이미지를 사람이 직접 분류했을 때(약 5%)마저 넘어섬
🔑 "잔차"라는 이름: 층이 만들 이상적 출력 H(x)에서 입력 x를 뺀 F(x)=H(x)−x가 통계의 잔차(관측값−기준값). 최종 출력은 x를 더해 H(x)로 복원 — 차이만 다듬으니 학습이 수월.
깊이의 벽은 그렇게 무너졌습니다. 이미지 진영은 이 지름길로 사람을 앞질렀습니다.

🧭 기억할 것은 문제의 모양

신호가 긴 사슬을 거치며 점점 흐려졌고
그 사슬을 건너뛰는 지름길을 놓아
신호가 곧장 흐르게 하자 벽이 뚫렸다
🔑 곧 걸어갈 언어의 길에서, 사람들은 단어를 하나씩 순서대로 처리하다 앞 단어의 기억이 뒤로 갈수록 흐려지는, 뿌리가 똑 닮은 벽을 만납니다. 먼저 꺼낸 해법도 "정보가 곧장 흐르는 통로를 터 준다"는 지름길과 같은 발상.
단, 언어에는 이미지에 없던 벽이 하나 더 남아 있었고 — 그것을 뚫은 열쇠가 앞에서 얼굴을 비친 어텐션입니다.
연도와 이름은 잊어도 됩니다. '긴 사슬 → 신호 소실 → 지름길로 돌파'라는 모양만 손에 쥐면 됩니다.

📌 이것만은 꼭 — 핵심 6문장

21998의 발상은 데이터·계산력 부족으로 잠들었다가, 대규모 데이터셋 + GPU로 부활
32012 AlexNet(ReLU·dropout·GPU) top-5 15.3% — 딥러닝 부활의 방아쇠

✅ 정답 & 해설

A1. 특징을 사람이 정하지 않고 픽셀에서 신경망(필터)이 스스로 배우게 함. 같은 필터를 전체에 재사용해 위치와 무관하게 무늬를 인식.
A2. 데이터·계산력 부족. 판을 뒤집은 두 조건 = 대규모 라벨 데이터셋(+ILSVRC)과 GPU 병렬 계산.
A3. ReLU·dropout·GPU(2장). 과적합 = 훈련 데이터를 이해 대신 외워 연습은 다 맞고 새 문제에서 무너지는 현상.
A4. 어느 선 이상 깊으면 훈련에서마저 성적이 나빠짐(학습 자체 불가). 원인 = 되짚는 신호가 층마다 1보다 작은 기울기에 곱해져 0에 수렴.
A5. ① 지름길은 기울기 1이라 신호가 안 깎이는 고속도로 ② 필요 없는 층은 F(x)=0으로 항등 변환이 쉬움 → 마구 쌓아도 안 나빠짐.
A6. 연도·이름이 아니라 문제의 모양(긴 사슬→신호 소실→지름길 돌파). 언어의 닮은 벽 = 단어를 순서대로 처리하다 앞 단어 기억이 흐려지는 것.
A6의 '모양'이 다음 강의로 이어지는 다리입니다.
