WebChat에서 주고받은 직접 메시지는 기본적으로 하나의 이어지는 대화인 메인 세션으로 들어갑니다.

메인 세션

  • WebChat의 직접 메시지는 기본적으로 하나의 이어지는 대화인 main session으로 들어갑니다
  • 이 대화의 표준 키는 agent:<agentId>:main이며, 웹 앱에서는 Home 화면으로 엽니다
🎯 대화의 연속성은 화면만이 아니라 — 설정·세션·워크스페이스에 남는 정보와 함께 읽습니다
화면의 연속성과 저장된 연속성은 다른 것입니다.

❓ 이해도 확인

Q1. 메인 세션의 표준 키는?
A1. agent:<agentId>:main. 웹 앱에서는 Home 화면으로 연다.
Q2. "완료했다"를 확인하려면 어느 줄을 보나?
A2. assistant 줄의 text나 toolCall이 아니라 — toolResult 줄의 content·details. toolCallId로 요청과 짝짓는다.
Q3. 설정 파일·세션 기록·워크스페이스의 관계는?
A3. 같은 파일이 아니며 각자 역할이 다르다. 설정은 openclaw.json, 세션은 에이전트별 SQLite, 워크스페이스는 파일 도구의 기본 작업 폴더.
Q2가 이 소단원의 결론입니다.
