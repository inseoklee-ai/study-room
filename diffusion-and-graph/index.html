확산 — 분자·결정 · 그래프 — 원자·기상

방금 확산으로 단백질 뼈대를 만들었습니다. 같은 뼈대가 두 번 더 갈아탑니다 — 약이 되는 분자와 새 물질. 그리고 그래프 신경망이 원자 사이 힘과 전지구 날씨로 주인공이 됩니다.

🗺️ 두 발상, 네 갈래

확산 (⑥)

약물 분자(주머니에 맞는 것을 새로 그림)와 결정 구조(없던 물질). 흩뜨렸다 되돌리기 — 흩뜨리는 것만 바뀐다

그래프 (⑦)

원자 사이 힘과 전지구 기상. 방정식을 푸는 대신 학습으로. 점과 선, 이웃끼리 주고받기

🎯 한 줄 — 그림·단백질 뼈대·약물 분자·결정은 분야도 자료도 다른데 계산의 뼈대가 같다. "확산 기반"이라는 말을 보면 무엇을 기대할지 바로 안다: 없던 걸 만들되 쓸 만한지는 따로 확인.
픽셀, 원자 좌표, 분자의 결합, 결정 격자 — 무엇을 흩뜨렸다 되돌릴지만 바뀝니다.

없던 분자와 없던 결정

주머니에 맞는 분자 · 없던 결정 구조

⑥ 확산
확산이 그림에서 시작해 단백질 뼈대로, 이제 약물 분자와 결정 구조로 갑니다.

♻️ 절차는 그대로, 흩뜨리는 것만 바뀐다

분야무엇을 흩뜨리나
그림픽셀 값
단백질 뼈대원자의 3차원 좌표
약이 될 분자원자와 결합
새 결정원자와 좌표와 격자
뿌린 잡음을 알아맞혀 거꾸로 걷어 낸다뼈대가 넷 다 같다 — 새 분야에서 "확산 기반"을 보면 무엇을 기대할지 안다
없던 것을 만들어 내되, 만든 것이 쓸 만한지는 따로 확인해야 한다는 것 — 이 사실 하나만 알아도 새 분야가 읽힙니다.

💊 주머니에 맞는 분자를 그려 낸다

  • 오래된 방식은 뒤지기 — 보유 화합물 수십만 개를 표적에 하나씩 붙여 보고 점수 좋은 걸 고른다(가상 스크리닝, 붙여 보는 계산이 도킹). 창고에 답이 없으면 없는 것
  • 최근 방향이 바뀌었다 — 표적 홈 모양을 조건으로 주고 그 자리에 맞는 분자를 새로 그린다(창고를 뒤지는 대신 맞춤으로 짓기). 여기에 확산
분자는 돌려놓아도 같은 분자라, 모델이 두 성질을 갖춰야 한다 — 에너지·점수 같은 방향 없는 답은 어떻게 돌려도 똑같이(불변), 힘·좌표 같은 방향 가진 답은 30도 돌리면 정확히 30도 돌아(등변). 검색어에 equivariant가 붙어 있으면 이 성질을 갖췄다는 뜻.
🔬 억지로 온갖 방향을 돌려 가며 보여 주면 값이 비싸고 안 본 각도에서 흔들립니다. 더 나은 길은 애초에 흔들릴 수 없게 — 거리·각도처럼 회전에 안 변하는 값만 재료로 쓰는 것. 이 공유 성질이 갈래들이 서로 빠르게 옮겨 붙는 이유이기도 합니다. 이 방향이 열린 건 홈과 리간드(결합 상대) 짝이 공개 DB에 수십만 건 쌓인 덕입니다.

🖱️ 설치 없이 눌러 보기 — GenMol

  • NVIDIA가 올려 둔 페이지는 로그인·키 없이 Experience 탭에서 그대로 돈다. 예제 중 실제 약 바리시티닙을 고르면 분자식 칸이 문자열로 채워진다(원자·결합을 알파벳·괄호로 한 줄에 적은 표준 표기)
  • 맨 끝 [*{20-20}]가 새로 만들 조각 — 별표가 "여기를 채워라", 중괄호 두 숫자가 채울 길이(20-20이면 스무 토막). Run을 누르면 채운 분자들이 구조식으로, 점수가 색으로
점수는 QED — 너무 크지 않은지, 기름·물 사이 성질이 적당한지 잣대를 합쳐 0~1로. 높다고 약이 된다는 뜻은 아니고 먼저 볼 것을 고르는 자. 분자식만으로 계산돼 나온 것들을 한눈에 줄 세운다.

조각을 고정한 채 나머지를 채우는 이 방식은 단백질 뼈대를 고정하고 서열을 입히는 것과 성격이 같다 — 이쪽도 확산인데 다루는 게 좌표가 아니라 글자. 글자열엔 잡음을 못 뿌리니 글자를 무작위로 지웠다 되채운다(discrete diffusion)

개수 슬라이더 30은 서른 개를 만들라는 요청값이고, 중복·실패를 걸러낸 뒤라 화면엔 대개 열 개 안팎이 남습니다. 서른이 안 나와도 잘못 누른 게 아닙니다.

🕰️ 열린 것 ≠ 오늘 도는 것 — 그리고 도킹

  • 분자 생성 대표 DiffSBDD(코드 MIT, 가중치 CC BY 4.0)의 공식 코랩은 2022년 판에 못 박혀 있어, 코랩 파이썬이 3.12로 오른 지금 설치 15줄 중 7줄이 실패(rdkit 포함). TabPFN에선 원인이 라이선스, 여기선 시간 — 저장소는 마지막 손질 날짜를 함께 본다
  • 오늘 손에 잡히는 쪽은 도킹 — 고전 방식 AutoDock Vina(아파치 2.0, 그래픽카드 불필요). pip install vina meeko gemmi rdkit 10초
단백질·분자를 PDBQT 형식으로 바꾸고 어디를 뒤질지 상자로 지정해야 한다(잘못 잡으면 The ligand is outside the grid box). 시간은 분자가 가른다 — 작은 분자는 5초, 실제 약 이매티닙(회전 결합 7)은 권장 설정으로 6분 40초. "그래픽카드 필요 없다"와 "몇 초에 끝난다"는 다르다.
결과 자세마다 REMARK VINA RESULT: -12.770 처럼 점수가 붙습니다(음수일수록 강함). 그 숫자 하나를 믿지 말고, 결합이 이미 알려진 분자를 같은 상자에 넣어 받은 점수를 옆에 놓고 순위로 읽는 것이 기준선입니다. 낱말: 구조 기반 신약 설계·포켓 조건부 생성·도킹.

💎 없던 결정 구조를 만든다 — MatterGen

물질 찾기는 오래 시행착오였다(굽고 재고 다시 굽고). 2010년대에 컴퓨터로 후보를 미리 걸러 내는 방식이 자리 잡아 계산된 물질 수십만 건이 공개됐다 — 그래도 여전히 뒤지기(아는 구조를 조금 바꿔 보기)였다. MatterGen은 결정 구조 자체를 생성한다.

  • 어느 원소를 몇 개, 얼마만 한 상자에 어떤 좌표로 배치할지를 한꺼번에. "자기 성질이 이 정도인 물질"처럼 조건도 건다
  • 결정은 같은 무늬가 무한 되풀이되는 구조, 그 무늬 하나가 담기는 상자가 단위 격자. 좌표는 상자 안에서만 뜻이 있고 상자도 늘거나 기운다 → 원자 종류·좌표·상자 모양 셋을 함께 흩뜨렸다 함께 되돌린다
코드·가중치 모두 MIT, 최근 갱신 2026년 7월. 공식 코랩이 없어 환경을 직접 만든다(무료 T4에서 넉넉, 설치 2분·생성 8분 — 되돌리기를 천 번 밟아서). 조건은 출처만 밝히면 돼 걸릴 것 없다.
🔬 공식 코랩 없는 저장소를 코랩에서 열 때, uv venv와 uv pip install을 한 줄로 붙이고 mattergen-generate 앞에 .venv/bin/을 붙이며 unset UV_SYSTEM_PYTHON을 넣는 것이 요령입니다(코랩은 ! 줄마다 새 셸이라 가상환경이 다음 줄에 안 남음). 📚 A generative model for inorganic materials design, Nature 2025.

📏 결정 판정선 — 있을 수 없는 것 걷어내기

존재한 적 없는 결정 구조가 CIF 표준 파일로 여러 개 나온다. 3차원으로 띄우면 원자들이 규칙적으로 배열된 모습.

가장 가까운 원자쌍이 0.5옹스트롬보다 멀 것좋은 구조를 고르는 자가 아니라, 있을 수 없는 구조를 걷어 내는 자
원자 둘이 0.5옹스트롬보다 가까우면 결합이 아니라 서로 겹쳐 놓인 것이라 어떤 물질로도 안 만들어진다. 잘 나온 구조는 대체로 2~3옹스트롬 대, 결합 종류에 따라 1.5옹스트롬 언저리도 정상.
  • 생성된 게 진짜 만들어지는지는 이 도구가 답하지 않는다 — 계산상 안정해 보이는 것과 실험실에서 합성되는 것은 다르다. 그 사이를 메우는 게 이어서 볼 원자간 퍼텐셜
재료 생성은 오늘 여덟 중 손이 가장 많이 갑니다. 시간이 빠듯하면 공식 코랩이 여럿인 원자·기상 쪽을 먼저 열고 이쪽은 나중에 돌리세요. 낱말: 결정 구조 생성·물성 조건부 생성·안정성 선별.

자연을 계산하는 대신 배우는 길

관계를 자료로 · 원자 사이 힘 · 전지구 예보

⑦ 그래프
지금까지는 없던 것을 만드는 쪽이었습니다. 이 절은 성격이 다릅니다 — 원래 방정식을 풀어 얻던 답을 학습으로 대신 얻는 갈래이고, 그래프 신경망이 주인공입니다.

🔗 관계를 자료로 쓴다 — 간선 하나 차이

논문끼리 인용 관계를 정리한 연습용 자료 Cora — 논문 2,708편, 간선 10,556개. 각 논문은 어떤 단어가 나왔는지로 표현되고 일곱 주제로 분류. 정답이 붙은 논문은 140편뿐이라, 관계를 안 쓰면 나머지 2,568편이 아무 단서도 못 준다.

모델 (매개변수 23,063로 동일)인용학습시험 정확도
그래프 신경망사용3.7초81.5%
같은 크기의 일반 신경망무시2.0초56.4%
크기는 그대로, 간선만으로 25%포인트이웃 논문의 주제를 참고해 라벨 없는 논문에서도 단서를 끌어온다
이것이 다음 두 갈래에서 벌어지는 일과 같다 — 원자 하나의 상태는 이웃 원자가, 대기 격자점 하나의 다음 값은 이웃 격자점이 정한다. 관계가 답을 담은 자료에선 관계를 쓰는 것 자체가 큰 이득. 오늘 여덟 중 가장 싸게 손에 잡히는 자리이니 건너뛰지 말 것.
pip install torch-geometric scipy, 그래픽카드 불필요. 라이브러리에 든 Cora를 그대로, 크기 같은 모델 둘을 200에폭씩(하나는 간선 사용, 하나는 버림). 간선을 버린 쪽이 몇 포인트 떨어지는지가 이 발상의 값입니다.

⚛️ 원자 사이의 힘을 학습으로 — CHGNet

  • 물질 성질은 원자들이 서로 얼마나 세게 끌고 미는지에서 나온다. 제대로 구하려면 양자역학 계산(밀도범함수이론, DFT) — 정확한 대신 느리다(원자 몇백 개에 시간 단위, 수가 늘면 훨씬 가파르게)
  • 최근 변화는 여러 원소를 한 모델이 다 다루게 된 것 — 예전엔 실리콘용·물용 따로. 지금은 주기율표 대부분을 아우르는 하나를 받아 바로 쓴다. 이 계열이 신경망 원자간 퍼텐셜
그래프가 가장 자연스럽게 맞는 데 — 원자를 점, 가까운 쌍을 선으로. 각 원자가 이웃에게 "나는 어떤 원소·너와 이만큼"을 받아 상태를 고치기를 반복(메시지 패싱). 퍼텐셜 = 배치가 갖는 에너지, 에너지가 내려가는 방향이 힘 → 힘 구하기와 퍼텐셜 구하기가 같은 말.
🔬 이웃하고만 주고받는데 멀리까지 전해지는 건 반복 덕 — 한 번이면 이웃, 두 번이면 이웃의 이웃. 실무 모델은 대개 서너 겹. 다만 전하 띤 이온처럼 거리가 멀어도 천천히 약해지는 상호작용은 잘 안 잡혀, 최신 모델이 따로 장치를 붙입니다. 📚 CederGroupHub/chgnet, GitHub.

📉 구조 이완 곡선을 본다

  • basics 노트북이 가장 짧은 진입로. 그래픽카드 없이도 use_device='cpu'로 돈다(작은 결정은 에너지·힘이 1초, 구조 이완도 몇 초)
  • 노트북 예제 구조를 그대로, 자기 구조가 있으면 CIF 하나. 넣으면 에너지와 각 원자에 걸리는 힘이 숫자로
숫자 하나가 아니라 곡선의 생김새가 판단 근거계단처럼 내려가다 평평해지면 자리 잡음, 끝까지 출렁이면 수렴 안 됨 → 그 결과는 쓰지 말 것
막히면 — 같은 계열 MACE도 좋은데 MIT인 것은 재료용 몇 개뿐이고 유기화학용·최신 범용판은 학술 전용. 이름이 비슷해 눈으로 못 가리니 저장소 표의 라이선스 칸을 한 줄씩 보고 받는다. 낱말: 원자간 퍼텐셜·메시지 패싱·구조 이완·분자동역학·ASE(모델과 계산을 잇는 표준 인터페이스).
구조 이완은 원자들이 조금씩 자리를 잡아 가며 에너지가 내려가는 과정입니다. CHGNet 라이선스는 BSD 3조항 계열인데 연구소 표준 문안이라 개선분 조항이 하나 더 붙습니다.

🌦️ 슈퍼컴퓨터가 하던 예보를 학습으로

날씨 예보는 오래 물리 방정식 풀이였다 — 지구를 격자로 나누고 각 칸의 기압·온도·바람을 놓고 유체 방정식을 시간 단계마다. 정확하지만 무거워 슈퍼컴퓨터를 운영. 2023년 딥마인드 GraphCast는 방정식을 안 풀고 지난 수십 년치 관측을 배워 열흘치 전지구 예보를 1분에 냈다.

  • 이름에 그래프가 든 이유 — 위도가 높을수록 칸이 촘촘해지는 왜곡을 피해 구를 거의 균일하게 덮는 점들을 이웃끼리 선으로 잇고, 원자간 퍼텐셜처럼 각 점이 이웃 정보를 받아 상태를 고치기를 반복. 다루는 게 원자에서 대기 격자점으로 바뀐 것뿐
  • 출발 조건을 조금씩 흔들어 여러 번 돌려 답이 얼마나 흩어지는지 보는 것이 앙상블 예보 — 답 하나가 아니라 답의 폭이 결과
뒤집은 것은 물리를 한 줄도 안 넣은 모델이 방정식 쪽과 겨룰 만하다는 결과 하나. 바탕엔 유럽 기상 기관의 수십 년치 재분석 자료(ERA5)가 공개돼 있었다(관측만으론 빈 곳이 많은데 물리 모델로 메워 균일 격자로 정리).
지역 농협 담당자가 골짜기 새벽 기온을 알고 싶을 때, 공개 모델·관측으로 좁은 구역을 여러 번 돌려 최저기온이 어느 범위에서 흔들리는지 확률로 봅니다.

위성 영상 사전학습

홍수·산불·작물 경계 찾기. 유럽 위성 영상이 아마존 클라우드에 인증 없이 최신 장면까지. 한 픽셀 10m라 넓은 것에 맞고 건물 한 채엔 성기다. 건물 윤곽은 항공 타일(0.13m)로 — 한 블록 90초에 경계 1,200여 개

위성 영상은 구름 90% 넘는 날도 흔하니 목록에서 구름 비율을 보고 고른다. segment-geospatial은 2026년 7월 판부터 지도 라이브러리가 필수 의존성에서 빠져, 안내대로만 하면 import leafmap에서 멈춘다 — %pip install segment-geospatial leafmap localtileserver로.
PINN(물리 정보 신경망)은 관이 벽에서 속도 0, 판 끝 온도 얼마 같은 경계조건을 반드시 지키게 합니다.

✅ 정답 & 해설

A1. 뼈대 = 뿌린 잡음을 알아맞혀 거꾸로 걷어 내며 만들기. 바뀌는 것은 흩뜨리는 대상 — 픽셀·원자 좌표·원자와 결합·원자와 좌표와 격자.
A2. 뒤지기는 가진 것 안에서만 고른다(창고에 없으면 없음). 포켓 조건부 생성은 홈 모양을 조건으로 맞는 분자를 새로 그린다.
A3. 원자 둘이 0.5옹스트롬보다 가까우면 결합이 아니라 서로 겹쳐 놓인 것이라 어떤 물질로도 안 만들어진다 — 있을 수 없는 구조를 걷어낸다(좋은 것 고르는 자 아님).
A4. 정답이 140편뿐이라, 이웃 논문의 주제를 참고해 라벨 없는 논문에서도 단서를 끌어온다. 관계가 답을 담은 자료에선 관계를 쓰는 것 자체가 이득.
A5. 날짜로 확인해 최신 쪽(저장소 설명 2026-08-06 상업 허용). 파일 안 문구가 낡아 화면에 옛 라이선스가 찍히는 것.
