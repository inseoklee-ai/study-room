# 블록 어휘 — 웹 덱과 PPT가 동시에 아는 것만 쓴다

덱 HTML 은 사람이 보는 웹 슬라이드이면서, `build_ppts.js` 가 읽어 PPT 로 옮기는 **원본**이다.
그래서 **변환기가 모르는 마크업을 쓰면 PPT 에서 조용히 뭉개진다.** 아래 표에 있는 것만 쓴다.

## 슬라이드 유형 — 변환기가 이 순서로 판정한다

| 조건 | PPT 결과 |
|---|---|
| `.cover` 안에 `<h1>` 이 있다 | 진한 초록 배경 표지면 (kick 대문자 · h1 · sub · 하단 워터마크) |
| `.part` 가 있다 | 크림 배경 파트 구분면 (`.pno` 번호 카드 · h2 · p · `.who` 칩) |
| 그 밖 전부 | 본문면 — `h2`(또는 h1) 제목 + 밑줄 + 블록 세로 배치 |

본문면은 블록 높이를 **자동으로 재서 한 장에 눌러 담는다**(`measure()` → `scale`).
넘치면 글자가 작아진다. 그래서 **한 슬라이드에 블록 5~6개까지**가 안전선이다.

## 본문 블록 — 왼쪽 마크업이 오른쪽 도형으로 바뀐다

| 마크업 | 웹 | PPT 렌더 |
|---|---|---|
| `<p>` | 문단 | 회색 본문 텍스트 |
| `<ul class="pts"><li>` | 불릿 목록 | `›` 초록 불릿 + 텍스트 |
| `<div class="steps"><div class="st"><span class="n">1</span><span class="t">…` | 번호 단계 카드 | 흰 카드 + 초록 번호 사각형 |
| `<div class="qa"><div class="q">` / `<div class="q a">` | 질문 / 정답 | 왼쪽 세로바 카드 — 질문 초록, 정답 금색 |
| `<div class="hl">` | 강조 띠 | 연배경 강조 카드 |
| `<div class="big">` | 큰 문장 | 진한 초록 배경 + 흰 큰 글씨 (`<span class="y">` 로 금색 강조) |
| `<div class="chain"><div class="cell"><small>1</small><b>…</b></div><span class="ar">→</span>` | 흐름 사슬 | 카드 3~5개 가로 배치 + 화살표 |
| `<div class="grid2">` 안에 `.box` | 2열 박스 | 카드 나란히 (`.box` 안 `h3` + `p`) |
| `<div class="box"><h3>…</h3><p>` | 단독 박스 | 카드 한 장 |
| `<table class="t">` (`th`/`td`) | 표 | 표 (헤더 초록) — **`class="t"` 를 빼면 웹에서 스타일이 안 먹는다** |
| `<pre>` | 코드 블록 | 모노스페이스 코드 카드 |
| `.grid3` · `.io` · `.paths`(`.pipe`/`.ph`/`.stp`) · `.lgd` | 3열·입출력·분기·범례 | 변환기는 알지만 **템플릿 CSS 에는 없다.** 쓰려면 CSS 를 함께 가져온다 — `.grid3` 은 `local-llm/` `decision-doc/`, `.paths` 는 `local-vs-api/` `pixels-sentences/`, `.io` 는 `two-requests/`, `.lgd` 는 `pixels-sentences/` |
| `.line2` `.flowf` `.tl` `.venn` `.qk` `.ladder` `.bars` 등 도해 클래스 (CSS 를 직접 얹어야 함) | 커스텀 SVG/도형 | **텍스트 170자 요약으로만** 들어간다 — PPT 를 생각하면 도해는 최소로 |

## 인라인 강조

`<b>` 굵게 · `<i>` 흐리게 · `<small>` 작게 는 그대로 옮겨진다.
색 강조는 클래스로 — `.g` 초록 · `.gold` 금색 · `.r` 붉은색 · `.b` 파란색 · `.p` 보라색.
`style="color:var(--gr)"` 형태도 인식하지만 **클래스를 쓰는 편이 안전하다.**

## 변환기가 무시하는 것

- `<h1>` `<h2>` `<h3>`(슬라이드 최상단 제목) — 제목으로 따로 처리하므로 블록에서 제외
- `<aside>` — PPT **발표자 노트가 아니라 아예 안 들어간다.** 웹 덱의 `S` 키 전용
- `<script>` `<style>`
- 알 수 없는 `<div>` — 블록 자식이 있으면 재귀, 인라인만 있으면 한 문단으로 취급 (텍스트는 유실되지 않는다)

## 한 슬라이드 권장 조합

```
h2 제목
<p> 도입 한 문단
블록 1~2개 (표 · steps · grid2 중 하나 위주)
<div class="hl"> 한 줄 요약
<aside> 발표 대본
```
