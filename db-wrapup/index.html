다섯 줄 요약

오늘 배운 것한 문장 정리내가 할 수 있는 행동
데이터베이스의 역할서비스의 '기억' — 데이터를 남기고 빠르게 찾아 줍니다새로고침해도 남아야 할 데이터를 구분합니다
역사와 갈래파일→SQL→NoSQL(4종)→클라우드로 발전했습니다표(SQL)와 유연한 상자(NoSQL)의 성격을 압니다
SQL 알아보기SQL은 거의 영어 문장이며, 코드는 AI가 씁니다SELECT … FROM … WHERE …를 말로 풀 수 있습니다
보안·백업SQL 주입은 파라미터화로 막고, 데이터는 백업으로 지킵니다AI에게 '파라미터화·해시·자동 백업'을 요구합니다
무료 DB 고르기무료 티어로 시작하되 한도·백업·정책을 압니다첫 서비스엔 Supabase(Postgres)를 후보로 둡니다
세 번째 열이 중요합니다. '안다'가 아니라 '한다'로 끝나야 강의가 남습니다.

여덟 걸음 되짚기 ①~④

①저장할 곳이 필요한 이유 — 메모리는 사라지고 DB는 남는다. 다른 건 규칙·속도·동시성 셋
②역사 — 파일(60s) → 표(1970 코드) → SQL(1974) → 오라클(1979) → NoSQL(2000s) → 클라우드. NoSQL = Not Only SQL
③SQL과 데이터의 모양 — CRUD · 표/행/열 · 1:N과 N:M · 색인 · 트랜잭션(ACID) · 정규화 · 마이그레이션
④사용자를 다루기 — 회원 표와 CRUD · 세션 vs 토큰 · 캐시와 Redis · 인증은 직접 만들지 않는다
되짚기는 빠르게 넘깁니다. 학습자가 "아 그거"라고 떠올릴 수 있으면 충분합니다.

여덟 걸음 되짚기 ⑤~⑧

⑤보안과 백업 — Bobby Tables와 파라미터화 · TalkTalk(15만 7천 명, 4,200만 파운드) · 최소 수집 · 3-2-1 규칙
⑥무료 DB 고르기 — Supabase·Neon·Turso · 로컬(SQLite·Docker) · 용량·일시정지·백업·정책·요금 다섯 점검
⑦실습 — PRD → 구조도 먼저 합의 → 로컬 SQLite로 만들고 → 클라우드(Supabase, RLS 켜기)로
⑧마무리 — 회고 네 질문과 핵심 정리 다섯 줄
🎯 강의를 꿴 한 줄 — 코드는 AI가 쓰고, 무엇을 어떤 모양으로 남기고 어떻게 지킬지는 내가 정한다

❓ 마지막 확인

Q1. 이 강의를 한 줄로 요약하면?
A1. 코드는 AI가 쓰고, 무엇을 어떤 모양으로 남기고 어떻게 지킬지는 내가 정한다.
Q2. AI에게 DB를 붙여 달라고 할 때 빠뜨리면 안 되는 조건 두 가지는?
A2. ① 접속 정보는 코드가 아니라 환경변수(.env)로 ② 값은 파라미터화 쿼리로 넣고 비밀번호는 해시로 저장.
Q3. 실습에서 클라우드(Supabase)로 옮길 때 반드시 켜야 하는 것은?
A3. RLS(행 수준 보안). 안 켜면 공개 키로 누구나 데이터에 접근할 수 있다.
세 문제 모두 '행동'을 묻습니다. 개념 암기가 아니라 실제로 요구할 문장을 답하게 하세요.
